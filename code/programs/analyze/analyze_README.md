# Module: analyze

**Run order:**

| Order | Script | Description |
|-------|--------|-------------|
| 1 | `01_summary_stats.R` | Summary statistics (means, SDs, etc.) |
| 2 | `02_analysis.R` | Main analysis / regression models |

**To run this module only:** `source("code/programs/analyze/analyze_run.R")`
